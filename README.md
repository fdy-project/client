# FDY: 종단간 암호화 문서 저장소

FDY는 서버 운영자를 포함해 누구도 저장된 문서를 열어볼 수 없도록 설계된 개인 문서 웹입니다.

---

## 보안 원칙

- **종단간 암호화**: 데이터는 브라우저를 떠나기 전에 암호화됩니다. 서버에는 암호문만 도달합니다.
- **영지식 설계**: 서버는 비밀번호도, 암호화 키도 알지 못합니다.
- **검증된 알고리즘**: AES-GCM, Argon2id 등 표준 암호화 스펙만 사용합니다.

---

## 동작 방식

### 키 구조

| 키 | 역할 |
|---|---|
| DEK (Data Encryption Key) | 문서를 직접 암호화하는 키. 브라우저에서 랜덤 생성됨 |
| KEK (Key Encryption Key) | DEK를 암호화하는 키. 사용자 비밀번호에서 유도됨 |

### 키 유도: Argon2id

비밀번호 하나에서 두 가지 값을 유도합니다.

- `AuthHash` — 서버 인증용. 서버가 아는 건 이 값뿐입니다.
- `KEK` — DEK 암호화/복호화용. 브라우저 밖으로 나가지 않습니다.

Argon2id는 메모리 집약적 설계로 GPU 병렬 공격에 강합니다.

### 이중 암호화 흐름
```
문서 → [DEK로 암호화] → 암호화된 문서
DEK  → [KEK로 암호화] → 암호화된 DEK
```

서버에 저장되는 건 암호화된 문서와 암호화된 DEK입니다.
복호화 키 체인의 시작점은 오직 사용자의 비밀번호입니다.

---

## 보안 보장 범위

**DB가 통째로 유출되더라도:**
- 비밀번호 원문은 복구 불가 (서버에 없음)
- 문서 내용은 복호화 불가 (KEK가 없으면 DEK를 못 풀고, DEK가 없으면 문서를 못 풂)

**서버 운영자도:**
- 문서를 읽을 수 없음

**기술 스택:**
- AES-GCM 256-bit
- Argon2id (PHC winner)
- Web Crypto API
